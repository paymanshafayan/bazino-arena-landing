## حکم تطبیق چشمی (این جلسه)

دمو فعلی یک **پنل ادمین/داشبورد تخت** است. مرجع یک **صفحه سینمایی Hub** است:
هیرو تمام‌عرض با عکس، بنر بازی داخل پنل، کارت مسابقه با سید+آواتار واقعی،
قهرمان با جام+تاج گل بالای عکس دایره‌ای، فینال زیر قهرمان.

شکاف اصلی **شکل و چیدمان زون‌ها** است، نه پالت نئون.

| زون | تشابه تقریبی | اولویت |
|---|---|---|
| هدر (ناو+زبان+یوزر) | ~70٪ | P2 |
| هیرو سینمایی | ~25٪ | **P0** |
| تب‌های Weekly / Special | ~40٪ | **P0** |
| سایدبار تورنمنت‌ها | ~45٪ | P1 |
| هدر پنل براکت (بنر FC26) | ~20٪ | **P0** |
| آناتومی کارت مسابقه | ~40٪ | **P0** |
| خطوط براکت + تقارن دو طرفه | ~55٪ | P1 |
| بلوک CHAMPION + محل فینال | ~30٪ | **P0** |
| فوتر | ~65٪ | P2 |

## ۲) بازسازی جزءبه‌جزء

### A. هدر — نزدیک است، فرم ویجت‌ها غلط است

**مرجع**
- لوگو: آیکون گیم‌پد نئون فیروزه→صورتی + `BAZINO` ایتالیک گرادیان + `GAMING CLUB` با tracking زیاد
- ناو وسط، uppercase، `EVENTS` سرخابی با آندرلاین نئون
- زبان: کپسول بوردر فیروزه‌ای (`🌐 TR ▾`)
- زنگ + دات نوتیف
- یوزر: **عکس دایره‌ای واقعی** + `ArmanK` / `#BZN1024` فیروزه‌ای داخل چیپ بوردر‌دار

**ما**
- ساختار درست است
- آواتار حرفی، چیپ یوزر بدون بوردر کپسول، گیم‌پد SVG غیرمرجع

**کار**
- چیپ زبان و یوزر را کپسول بوردر فیروزه کن
- آواتار هدر = عکس (فعلاً asset دمو)
- ناو: یک `SHOP` اضافه طبق مرجع نگه داشته شود (عمدی در ماکاپ)

### B. هیرو — بزرگ‌ترین شکاف صفحه

**مرجع = بنر سینمایی سه‌ستونه، نه تیتر چپ‌چین روی پس‌زمینه خالی**

- ستون چپ: عکس ستاپ گیم RGB/نئون، روی آن دست‌نویس سرخابی `Play / Compete / Win`
- وسط: جام نئون + `TOURNAMENT` سفید / `BRACKETS` گرادیان ماژنتا→بنفش، خیلی بزرگ و **وسط‌چین**
- زیرتیتر: `LIVE & PAST TOURNAMENT` سفید + `RESULTS` فیروزه، letter-spacing زیاد
- تگ‌لاین روشن باشد (الان در CSS `display:none` است — باید برگردد)
- ستون راست: عکس پلیر هدست نئون، روی آن دست‌نویس `Good Games / Good People`

**کار**
1. هیرو را `display:grid; grid-template-columns: 1fr minmax(640px, 2fr) 1fr` کن
2. دو عکس full-bleed با ماسک تیره به سمت وسط
3. تایتل را دوباره **وسط‌چین** کن (دمو v2 اشتباه چپ‌چین شد)
4. اسکریپت‌ها را روی خودِ عکس بنشان، نه روی navy خالی
5. فونت اسکریپت: یک display script باندل محلی (نه وابستگی به Brush Script سیستم)

Asset لازم: `hub/bracket-demo/hero/setup.jpg` و `hub/bracket-demo/hero/player.jpg`
(از ماکاپ کراپ، یا جنریت نزدیک به مرجع؛ کیفیت PDF فعلی کافی نیست)

### C. تب‌ها — شکل دکمه عوض شود

**مرجع**
- دو قرص عریض هم‌اندازه، **روی لبه پایین هیرو** (overlap)
- Weekly روشن: فیل سرخابی/بنفش، آیکون تقویم داخل مربع گرد، متن سفید، زیرنویس
- Special خاموش: فیل navy، بوردر فیروزه، ستاره فیروزه

**ما:** outline کوچک، چپ‌چین، بدون overlap هیرو، حالت on بنفش کم‌رنگ نه فیل سرخابی

**کار:** ارتفاع ~56–64px، عرض هر تب ~420px، `border-radius: 14px`، Weekly = fill magenta، Special = ghost cyan. موقعیت: `margin-top: -28px` نسبت به هیرو.

### D. سایدبار

**مرجع**
- فیلترها **یک ردیف**: ALL | CURRENT (سبز توپر) | UPCOMING | COMPLETED
- کارت: کاور landscape درشت (~88×48) چسبیده به چپ
- سه خط: نام بازی بولد، `Weekly Tournament #N`، تاریخ + `32 Players`
- `🏆 COMPLETED` طلایی پایین-راست + شِورن
- انتخاب‌شده: حلقه ماژنتا + glow

**ما:** کاور 62×34، فیلتر wrap دوتایی، متن فشرده، آخرین آیتم LIVE (داده غلط)

**کار**
- عرض سایدبار را ~280px کن
- فیلتر nowrap + اسکرول افقی اگر لازم شد
- کاور را بزرگ‌تر و object-fit cover
- همه ۷ آیتم COMPLETED مطابق مرجع
- badge را از روی متن جدا کن (الان overlap می‌کند)

### E1. هدر پنل براکت — بنر بازی، نه تامبنیل

**مرجع:** نوار سینمایی تمام‌عرض داخل پنل
- چپ: لوگوی بزرگ `EA SPORTS FC26`
- راست: بازیکن پیراهن سفید `#26` در استادیوم + شعار `PLAY COMPETE BE A LEGEND`
- زیر/روی بنر: `WEEKLY TOURNAMENT #13` ماژنتا + تاریخ + 32 PLAYERS + COMPLETED طلایی
- کل پنل بوردر فیروزه‌ای با گوشه گرد ~16px

**ما:** یک img کوچک + h2

**کار:** `bk-panel-head` را بنر 72–88px با تصویر زمینه + گرادیان تیره از چپ، لوگو FC روی چپ، بازیکن روی راست. متن متا زیر بنر یا overlay چپ.

Asset: `hub/bracket-demo/covers/banner-fc26.png` موجود است — باید واقعاً استفاده شود (الان import نشده).

### E2–E3. کارت مسابقه + درخت

**آناتومی کارت مرجع (مهم‌ترین شکل جزء)**

```
┌─────────────────────────┐
│ 1   (avatar) ArmanK   4 │   ردیف برنده: نام سفید، اسکور طلایی درخشان
│─────────────────────────│
│ 32  (avatar) RezaFun  1 │   ردیف بازنده: کم‌رنگ
└─────────────────────────┘
```

- سید **باید دیده شود** (الان `.bk-seed { display:none }` — حذف این قانون)
- آواتار **عکس دایره‌ای** نه حرف
- عرض کارت ~132–140px، ارتفاع ردیف ~28px، radius 8px
- بوردر ملایم آبی، بدون wash نارنجی روی کل ردیف (فقط اسکور برنده طلایی)

**درخت**
- ۸ ستون: R32 | R16 | QF | SF | FINAL | SF | QF | R16 | R32
- خطوط فیروزه نئون، در راندهای راستِ نزدیک فینال کمی ماژنتا
- SF چپ مرجع: کارت دو نفره (نه تک‌ردیفی که الان در `LSF` داریم)
- فینال **زیر** قهرمان است نه بالای آن

**کار فنی پیشنهادی:** از درخت recursive فعلی به **۸ ستون CSS grid** برو
(`grid-template-columns: repeat(4, 140px) 180px repeat(4, 140px)` + `grid-template-rows` برای 8 اسلات R32).
خطوط را با SVG overlay یا pseudo روی سلول‌ها بکش تا هندسه مرجع دربیاید.
درخت flex فعلی علت اصلی «شکل اجزاء» غلط است.

سیدهای R32 چپ مطابق مرجع:
`1/32, 17/–, 8/25, 9/24, 4/29, 13/20, 5/28, 12/21`
(بعضی ردیف‌های پایین مرجع سید دوم را نشان نمی‌دهند — همان را حفظ کن)

### E4. CHAMPION — ترکیب را invert نکن

**مرجع (از بالا به پایین، وسط پنل)**
1. جام طلایی با **تاج گل** + glow قوی
2. کلمه `CHAMPION` طلایی tracking
3. عکس دایره‌ای بزرگ بازیکن (~72px) با حلقه طلایی
4. `ArmanK` + `#BZN1024`
5. **زیر همه این‌ها** کارت فینال دو ردیفه (`ArmanK 5` / `Mahan10 3`) با بوردر طلایی

**ما:** کارت فینال بالاست؛ قهرمان داخل مستطیل طلایی با آواتار حرفی است. این همان «شکل جزء» است که کاربر دید.

**کار:** مستطیل طلایی پر را حذف کن. ترکیب باز (trophy + photo + متن) با radial glow. فینال را `order` پایین بیاور.

### F. فوتر — محتوا درست، آیکون‌ها ضعیف

مرجع: دایره نئون رنگی دور هر آیکون (پین ماژنتا، ساعت قرمز، واتساپ سبز، اینستا گرادیان) + جداکننده عمودی بعد لوگو + شعار اسکریپت راست.
کار: حلقه 36px با glow، جداکننده، اسکریپت راست را پررنگ‌تر.

## ۳) ترتیب اجرا (برای رسیدن به ≥۹۰٪)

فازها باید **جدا اسکرین شوند** تا هر زون با مرجع چشم‌مقایسه شود.

| فاز | هدف | فایل‌ها |
|---|---|---|
| **0. دارایی** | کراپ/جنریت هیرو چپ+راست، بنر FC26، ۱۲–۱۶ آواتار چهره دمو، فونت اسکریپت محلی | `hub/bracket-demo/{hero,avatars,covers}/` |
| **1. اسکلت زون** | هیرو سه‌ستونه + تب overlap + سایدبار عریض‌تر + بنر پنل | `BracketDemo.tsx` + css layout only |
| **2. کارت + ستون براکت** | سید روشن، آواتار عکس، grid ۸ستونه، SF دوطرفه | جایگزینی `TreeNode` |
| **3. قهرمان** | invert فینال/جام، تاج گل، عکس دایره‌ای، حذف باکس طلایی | css `.bk-center` |
| **4. پرداخت بصری** | فیلتر سایدبار تک‌ردیف، کاور بزرگ، فوتر حلقه‌نئون، چیپ هدر | css polish |
| **5. مدرک** | اسکرین full + compare کنار مرجع؛ در چت نشان بده | `hub/analysis/shot.mjs` |

توقف هر فاز: اسکرین همان زون در کنار کراپ مرجع. اگر شکل جزء نخورد، رنگ را دست نزن.

## ۶) معیار قبول (چشم + چک‌لیست، نه فقط متریک رنگ)

صفحه وقتی قبول است که این‌ها بدون توضیح در اسکرین دیده شوند:

1. هیرو عکس‌دار سه‌ستونه، تایتل وسط، تگ‌لاین可见، اسکریپت روی عکس
2. دو تب قرص‌شکل؛ Weekly فیل سرخابی؛ روی هیرو overlap
3. سایدبار با کاور درشت و فیلتر تک‌ردیف
4. بنر FC26 استادیوم داخل پنل
5. کارت = سید + عکس + نام + اسکور
6. CHAMPION = جام+تاج‌گل → عکس دایره → اسم؛ فینال زیر آن
7. براکت ۳۲ نفره دوطرفه بدون برش راست

متریک پیکسلی (`compare.py`) فقط بعد از این چک‌لیست، برای پالت/گرید.
