# Bazino Theme Design Skills Suite

این مخزن به سه مجموعه مهارت (Skills) تخصصی و پیشرفته جهانی در زمینه طراحی رابط و تجربه کاربری (UI/UX)، طراحی سیستم انیمیشن و فیزیک تعاملات، و شیوه‌نامه طراحی فرانت‌اند پیشرفته مجهز شده است.

---

## ۱. مهارت‌های رسمی انتروپیک (Anthropic Official Skills)
**مسیر:** `skills/anthropics/` و `.claude/skills/`

- **`frontend-design` (طراحی تمایزیافته و اصیل فرانت‌اند):**
  - رویکرد سرپرست طراحی (Design Lead): خلق هویت بصری یکتا، ارگانیک و اختصاصی بدون استفاده از پترن‌های کلیشه‌ای هوش مصنوعی (AI Slop/Clichés).
  - انتخاب حساب‌شده پالت رنگی (۴ تا ۶ متغیر پایه)، تایپوگرافی اصیل با کنتراست دقیق، و سلسله‌مراتب بصری داده‌محور.
  - جلوگیری از کلود-کلیک‌ها (عدم استفاده از فونت‌های پیش‌فرض تکراری، حذف برچسب‌های بی‌مورد، هماهنگی با محتوای واقعی گیم‌نت و لایسنس‌ها).
- **`theme-factory` (کارخانه قالب‌سازی و پالت‌های استاندارد):**
  - متغیرهای استاندارد CSS، توکن‌های طراحی، تایپوگرافی جفتی (Header/Body) و مدیریت تم‌های تیره/نئونی.
- **`web-artifacts-builder` & `webapp-testing`:**
  - ساخت کامپوننت‌های پایدار فرانت‌اند و تست‌های جامع عملکردی و بصری.
- **`algorithmic-art` & `canvas-design`:**
  - شیدرهای گرافیکی تعاملی Canvas/WebGL، پارتیکل‌های معلق، و المان‌های فضایی ۳D.

## ۲. مهارت‌های امیل کوالسکی (Emil Kowalski Design Engineering & Animation)
**مسیر:** `skills/emilkowalski/` و `.claude/skills/`

- **`emil-design-eng` (مهندسی طراحی و جزئیات پنهان):**
  - تمرکز بر جزئیات نادیده که در کنار هم محصولی چشم‌نواز خلق می‌کنند (*Unseen details compound*).
  - فرمت جدول بازبینی استاندارد (`Before | After | Why`) برای هر کامپوننت.
  - تعاملات بلادرنگ با فیدبک آنی کلیک و حالت `:active` (مثل `transform: scale(0.97)`).
- **`animate` (اصول متحرک‌سازی فیزیکی و اسپرینگ):**
  - اجرای دقیق توالی ۵ مرحله‌ای انیمیشن: تعیین ضرورت انیمیشن (gatekeeper)، تعیین هدف (Feedback, Spatial consistency, State indication)، انتخاب ابزار بهینه، منحنی‌های Easing واقعی بدون تقریب، و رعایت `prefers-reduced-motion`.
- **`animation-vocabulary` & `apple-design`:**
  - طراحی عمق فضایی (Spatial depth)، فیزیک سیال و ژست‌های لمسی روان.
- **`improve-animations` & `review-animations`:**
  - ممیزی نرخ فریم، حذف Layout Thrashing و تبدیل انیمیشن‌های سنگین به GPU-accelerated (`transform`, `opacity`).

## ۳. مهارت فوق‌پیشرفته UI/UX Pro Max
**مسیر:** `skills/ui-ux-pro-max/` و `.claude/skills/ui-ux-pro-max/`

- **موتور هوش طراحی:**
  - شامل ۷۹ سبک طراحی تعاملی، ۱۹۲ پالت محصول و رنگ، ۷۴ ترکیب تایپوگرافی، ۱۱۹ راهنمای UX، ۲۵ نوع نمودار و ۲۲ استک نرم‌افزاری.
- **جستجوگر CLI محلی:**
  ```bash
  python skills/ui-ux-pro-max/cli/src/ui_ux_pro_max/search.py "<query>" --domain <style|ux|color|typography|icons|chart|landing>
  ```
- **چک‌لیست کیفیتی:**
  - کنتراست استاندارد WCAG 4.5:1 برای دارک مود و OLED.
  - حداقل ابعاد لمسی ۴۴×۴۴ پیکسل در موبایل با فاصله حداقل ۸ پیکسل.
  - پیشگیری از شیفت چیدمان تجمعی (CLS < 0.1).

## نحوه استفاده الزامی در طراحی هر قالب جدید
هر بار که کارفرما درخواست طراحی، بازطراحی یا بهینه‌سازی قالب (Theme) یا کامپوننت‌های بصری پورتال را ارسال کند، ایجنت موظف است:
1. ابتدا با استفاده از مهارت **Anthropic `frontend-design`** هویت بصری یکتا و ضد کلیشه را تدوین کند.
2. با **UI/UX Pro Max** پالت دقیق رنگی، توکن‌های کنتراست بالا و اصول ریسپانسیو را استخراج نماید.
3. با مهارت‌های **Emil Kowalski (`animate` و `emil-design-eng`)** سیستم میکرواینتراکشن، حالت‌های دکمه‌ها و فیزیک حرکتی را بدون هیچ‌گونه افت فریم پیاده‌سازی کند.
4. جدول بازبینی Before/After را برای تمامی تغییرات استایل ارائه دهد.
